In the previous blog of this series:

I showed you the structure of a compiled Java class file, and walked you through each component of it, giving you a brief explanation about its purpose and what it does in the JVM execution process. I broke the class file structure into five major parts, each part contains other parts.

The first major part is the Class File header. It contains three minor parts which are the magic bytes, minor version, and major version bytes. This part is essential for any JVM implementation to make sure this is a class file and know which Java version it was compiled against.

The second major part is the Constant Pool. It contains some constants and references to objects and classes and other things that are used and often referenced during the JVM execution process by different JVM core components.

Then I talked about Access Flags, This Class, and Super Class bytes. Access flags give you some metadata about the class like if it was public or private, abstract or interface, and other flags discussed in this section. This class contains a reference to a constant pool entry that contains the reference of this class. Super class contains a reference to a constant pool entry that contains the reference of the super class of this class if exists.

After that we talked about Interfaces, Fields, and Methods. Interfaces declare if the current class implements any interfaces and contains their references if exists. Fields are the variables and properties declared at the top of the class like global variables for example. Methods are the actual methods that this class file contains and they carry the core execution logic and JVM instructions.

Finally we talked about the Attributes. There are 23 different attribute type supported by the JVM, but not all of them are really important to implement a working JVM. I only talked about the Code_Attribute as it's the most important and the most common one as it holds the code array that is the array of JVM instructions required to perform certain logic or execute a certain method.
